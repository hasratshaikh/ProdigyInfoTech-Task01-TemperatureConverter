# 🌡️ Temperature Converter | Prodigy InfoTech Internship

A Python-based Temperature Conversion Application that converts temperatures between Celsius, Fahrenheit, and Kelvin. The application provides an interactive web interface for easy and user-friendly temperature conversion.

## 🚀 Project Overview

This project was developed as **Task 01** of my Software Development Internship at **Prodigy InfoTech**.

The application allows users to enter a temperature, select the original measurement unit, and instantly calculate the equivalent values in the other two temperature scales.

## ✨ Features

- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Interactive web-based interface.
- Simple and user-friendly design.
- Accurate temperature conversion formulas.
- Python-powered application.

## 🧮 Conversion Formulas

| Conversion | Formula |
|---|---|
| Celsius → Fahrenheit | (C × 9/5) + 32 |
| Celsius → Kelvin | C + 273.15 |
| Fahrenheit → Celsius | (F − 32) × 5/9 |
| Fahrenheit → Kelvin | (F − 32) × 5/9 + 273.15 |
| Kelvin → Celsius | K − 273.15 |
| Kelvin → Fahrenheit | (K − 273.15) × 9/5 + 32 |
